# Security

Please report a vulnerability privately, not in a public issue: use
**[Report a vulnerability](https://github.com/treehousetim/waffle/security/advisories/new)**
on the repository's Security tab. You will get a reply within a week.

Fixes go into the next release; see [CHANGELOG.md](CHANGELOG.md). How the
project defends its own dependencies is in
[docs/supply-chain.md](docs/supply-chain.md).
