# Documentation

Reference material that is too long-lived, or too long, to live in a comment.
AGENTS.md is the rulebook; these are the details it points at.

The index is the **Documentation** table in the [top-level README](../README.md#documentation),
so there is one list to keep current. Add a document per feature, named after
its slice, holding its design, its numbered failure list, and what was built,
and add a row to that table.
